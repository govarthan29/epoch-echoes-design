# Historical Collectibles Storefront Prototype

## Scope
Build a responsive, frontend-only visual prototype using static dummy content. No commerce platform, backend, authentication, payments, APIs, database, or external-service connections.

## Pages
- Home: premium exhibit-style introduction, collectible discovery, editorial features, merchandise categories, product grid, historical story, historical categories, seasonal collections, collection builder teaser, collector sets, wholesale, stories, newsletter, and footer.
- Collectible story: museum-style image and 3D-viewer placeholder, artifact facts, historical narrative, drawings, related inventions, and inspired merchandise.
- Shop: product listing with visual filters, price controls, sorting, and premium product cards.
- Product detail: image gallery, options, quantity, purchase-control mockups, details, shipping, inspiration story, and related products.
- Build Your Collection: tier selector, collectible selection cards, and visual progress counter.
- Wholesale: B2B content, buyer types, offering highlights, collections, and inquiry form.
- Static cart panel and responsive mobile navigation for a complete visual journey.

## Visual Direction
- Modern museum editorial style with warm ivory, charcoal, parchment, and restrained bronze accents.
- High-contrast serif display typography paired with a clean sans-serif interface font.
- Generous spacing, crisp rules, archival labels, patent-document motifs, and realistic retail photography.
- Restrained motion only for page entrance, image reveals, and subtle control feedback.

## Technical Details
- Keep TanStack Start routing and create one route file for every destination.
- Use reusable header, footer, product, collectible, and editorial components with centralized static data.
- Define all colors, typography, shadows, and presentation values as semantic tokens in the global design system.
- Use locally stored generated imagery; no hotlinked placeholders.
- Add unique search/social metadata to every content page.
- Verify the finished experience at desktop and mobile sizes, including navigation, forms, product controls, cart presentation, and page links.
